
# Project Brief: CampusDAO

## 1. Vision Statement

CampusDAO is a premium, institutional decentralized student governance platform. It aims to modernize university student unions by bringing transparency, verifiable voting, and decentralized treasury management to campus life. The product prioritizes institutional credibility and technical precision over typical Web3 visual tropes.

## 2. Core User Values

* **Transparency:** Every proposal, vote, and treasury move is verifiable on-chain.
* **Simplicity:** Blockchain complexity is abstracted away into familiar, high-performance UI patterns.
* **Institutional Credibility:** A design language that feels like a serious academic and administrative tool.
* **Participation:** Lowering the barrier to entry for student involvement in campus-shaping decisions.

## 3. Visual Identity (Institutional Minimalist)

* **Palette:** Near-black monochrome.
  * Background: `#08090A`
  * Surface: `#101112`
  * Accent: White (`#FFFFFF`)
* **Typography:** Inter (Sans-serif). Large editorial headings (64-72px), precise page titles (36-40px), and technical metadata labels (uppercase with increased tracking).
* **Aesthetic:** "Infrastructure-as-Design" (inspired by Vercel/Linear). Subtle borders (`#272829`), generous whitespace, and minimal rounded corners (8-12px).
* **Negative Constraints:** No neons, rainbow gradients, excessive glassmorphism, or "cyberpunk" aesthetics.

## 4. Feature Set

### Public Experience

* **Landing Page:** High-impact value proposition and public statistics (Treasury value, Member count).
* **About Page:** Educational content explaining the "Why" and "How" of CampusDAO.
* **Governance Overview:** A public window into active initiatives and the governance lifecycle (Propose → Discuss → Vote → Execute).
* **Public Treasury:** Real-time visibility into DAO holdings and transaction history.

### Authenticated Governance Application

* **Dashboard:** Personalized overview of voting power, participation metrics, and active proposals.
* **Proposals Feed:** Searchable and filterable list of current and historical initiatives.
* **Proposal Details:** Central hub for deep-diving into motivation, budget, implementation, and active discussion/voting.
* **Creation Wizard:** Multi-step flow for drafting and submitting new proposals.
* **Treasury Management:** Detailed asset breakdown and on-chain transaction logs.
* **Activity Log:** Comprehensive audit trail of all governance events.
* **My Governance:** Personal profile tracking individual contributions and delegation status.

### Global Interactions

* **Wallet Connection:** Secure authentication via MetaMask or WalletConnect.
* **Transaction Flow:** Explicit states for Pending, Confirmation, Success, and Failure to manage blockchain latency.
* **Global Search:** Command palette (Ctrl+K) for navigating proposals, members, and transactions.
* **Network Diagnostics:** Notifications and banners for handling network/chain status.

## 5. Technical Requirements

* **Framework:** Modern HTML/CSS with a component-driven architecture.
* **State Management:** Clear feedback loops for asynchronous blockchain operations.
* **Responsive Design:** Desktop-first with mobile-optimized layouts for voting and proposal reading.
* **Accessibility:** High contrast ratios, clear focus states, and semantic HTML for institutional compliance.

## 6. Success Metrics

* **Voting Turnout:** Percentage of total governance tokens used in active votes.
* **Proposal Velocity:** Number of community-drafted proposals moving to execution.
* **Treasury Transparency:** Reduction in "information asymmetry" regarding student union fund allocation.
